# Настройка Telegram-бота в @BotFather + получение chat_id

Токен у тебя уже есть. Ниже — что задать боту в @BotFather (профиль и команды) и как получить `chat_id` рабочей группы. Сами обработчики команд соберёт Claude Code по брифу — здесь только профиль и доступы.

---

## 1. Профиль бота (в @BotFather)

Открой @BotFather, выбери своего бота → `Edit Bot`, и задай:

**Имя (`Edit Name`):**
```
Хрустальный · Аудит концепции
```

**Описание (`Edit Description`)** — видно на пустом экране до /start:
```
Помогаем девелоперам коттеджных посёлков проверить концепцию до стройки: окупаемость, стратегия, риски. Практикующий девелопер, а не консультант. Нажмите «Старт».
```

**About (`Edit About`)** — короткая строка в профиле (до 120 символов):
```
Концепт-бюро «Хрустальный»: аудит и концепции коттеджных посёлков.
```

**Команды (`Edit Commands` → вставить блок целиком):**
```
start - Начать и подобрать формат
audit - Что такое аудит концепции
case - Получить обезличенный кейс
contact - Связаться с командой
```

**Картинка (`Edit Botpic`):** загрузить логотип «Хрустальный» (квадрат, navy-фон).

---

## 2. Получить chat_id рабочей группы продаж

1. Создай группу (или используй существующую) для входящих заявок.
2. Добавь в неё своего бота **и** служебного `@getmyid_bot`.
3. `@getmyid_bot` пришлёт `Chat ID` группы — это число, у супергрупп начинается с `-100…`.
4. Это значение → переменная `TELEGRAM_SALES_CHAT_ID`. После настройки `@getmyid_bot` из группы можно удалить.

> Запасной способ (без сторонних ботов): напиши любое сообщение в группе и открой в браузере
> `https://api.telegram.org/bot<ТОКЕН>/getUpdates` — в ответе найди `"chat":{"id":-100...}`.
> Минус: токен светится в адресной строке/истории браузера — после этого лучше его перевыпустить.

---

## 3. Безопасность токена
- Токен — только в ENV хостинга или в локальном `.env` (в `.gitignore`). Никогда в коде/репозитории/скриншотах.
- Если токен мог увидеть кто-то посторонний — @BotFather → `/revoke` → получить новый, старый перестанет работать.
- Webhook вешать на секретный путь (`TELEGRAM_WEBHOOK_SECRET`), а не на предсказуемый `/webhook`.
