## 0. Цель
Опубликовать готовый лендинг аудита концепции и поднять **рабочую лидогенерацию**: форма на сайте + Telegram-бот, который присылает заявки в группу продаж и сам ведёт короткую воронку. Плюс полный юридический контур по 152-ФЗ.
Дизайн и тексты лендинга **не менять**: палитра navy/белый, шрифт Manrope, монохром, обращение на «вы», без эмодзи и инфобиза, якорь «практикующий девелопер, а не консультант».

## 1. Входные файлы
- `audit-hrustalny.html` — лендинг. Внутри: инлайн-картинки base64, форма `#zayavka` (имя/телефон/регион/стадия + обязательный чекбокс согласия, success-state, TODO под endpoint), скролл-анимации (`#layers`, `#viz`), SEO (title/desc/OG/JSON-LD Service+FAQ).
- `privacy.html` — Политика конфиденциальности + Согласие на обработку ПДн (`#consent`), 152-ФЗ. Оператор: **ООО СЗ «Малоэтажный девелопмент», ИНН 3808278549**, Иркутск (юр. адрес — TODO).
- `masterplan.png` — картинка героя (лендинг ссылается на неё относительным путём).

## 2. Собранные значения
- `TELEGRAM_SALES_CHAT_ID = -5481376613` — группа продаж для заявок
- `ADMIN_USER_ID = 989604210` — ограничить админ-команды бота только этим ID

## 3. Решение по MVP-хранению лидов
**На старте — только Telegram:** заявки уходят карточкой в группу продаж, без таблицы. Это даёт быстрый запуск.
Фаза 2 (после теста): Google Sheets (`GOOGLE_SERVICE_ACCOUNT_JSON` + `SHEET_ID`) **или** БД на РФ-хостинге для строгого 152-ФЗ. Вопрос локализации ПДн (Railway вне РФ) вынести на согласование — не блокирует MVP.

## 4. Архитектура
Один сервис (просто деплоить):
- **FastAPI**: раздаёт статику (лендинг + юр. страницы), принимает `POST /api/lead`, держит Telegram-бот на webhook.
- На старте лиды → карточка в Telegram-группу. Хранилище подключается позже без переписывания логики (вынести функцию `save_lead()` за интерфейс).
- Анти-спам: honeypot-поле + rate-limit по IP + серверная валидация телефона.
- Доказательство согласия (152-ФЗ): с каждым лидом фиксировать `consent_version`, дату, IP, user-agent.

## 5. Задачи по шагам

### 5.1 Фронт
- Вынести инлайн-base64 из лендинга в `web/assets/` (jpg/png/svg), заменить на `<img src="/assets/...">`. Цель — HTML <300 КБ.
- Переименовать в `index.html`. `masterplan.png` положить в `web/assets/`.
- Форму подключить к `/api/lead` (fetch POST JSON), использовать готовый success-state, добавить обработку ошибок и блок повторной отправки.
- Cookie-баннер (согласие, запоминается в localStorage) + страница `/cookie`.
- Яндекс.Метрика (ID из `YM_ID`), событие `lead_submit` при успешной заявке.
- Проверить адаптив, `prefers-reduced-motion`, плавность скролл-анимаций.

### 5.2 Юридический контур (152-ФЗ)
- `privacy.html` → `/privacy`. Вставить юр. адрес и контакты оператора (спросить, не выдумывать).
- Согласие — `/privacy#consent`, факт согласия **писать на сервер** с каждым лидом (и в форме, и в боте).
- `/cookie` — Политика по cookie (по стилю `privacy.html`).
- Футер и форма: ссылки на политику/согласие; чекбокс обязателен (есть).

### 5.3 Бэкенд (FastAPI)
- `POST /api/lead`, тело: `{name, phone, region, stage, comment?, consent:bool, hp(honeypot), page_url}`.
- Валидация: имя ≥2, телефон по маске РФ, `consent==true`, `hp` пустой; rate-limit по IP.
- Действие: `save_lead()` (на старте — карточка в Telegram) → вернуть `{ok:true}`.
- CORS только на `ALLOWED_ORIGIN`. `/healthz`. Статика через `StaticFiles`.

### 5.4 Telegram-бот (python-telegram-bot 21.x)
Профиль настраивается в @BotFather (имя/описание/about/команды — см. `botfather-setup.md`). Команды:
```
start - Начать и подобрать формат
audit - Что такое аудит концепции
case - Получить обезличенный кейс
contact - Связаться с командой
```
Функции:
- **Уведомление о лиде:** карточка (имя, телефон, регион, стадия, источник, время) в группу `TELEGRAM_SALES_CHAT_ID` + инлайн-кнопки «Взять в работу / Квалифицирован / Отклонить» (меняют статус; на старте — просто пометка в сообщении).
- **Воронка в боте:** команды и диалог из раздела 6 ниже. Лид из бота идёт тем же `save_lead()`.
- Webhook `/telegram/<TELEGRAM_WEBHOOK_SECRET>`, `set_webhook` при старте. Админ-команды — только для `ADMIN_USER_ID`.

### 5.5 Деплой
- `Dockerfile` + `railway.json` (или `Procfile`). Один процесс: `uvicorn` (FastAPI) + бот на webhook внутри.
- Домен: поддомен (например `audit.hrustalni.com`) → custom domain → DNS CNAME. HTTPS автоматом.
- После деплоя: `set_webhook`, end-to-end тест формы и карточки в группе.
