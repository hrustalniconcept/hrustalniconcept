# Собранные значения для запуска (лист-передача в Claude Code)

> Реальный токен сюда НЕ вписываем — он живёт только в ENV хостинга. Этот файл можно коммитить.

## Готово
- `TELEGRAM_SALES_CHAT_ID = -5481376613`   — рабочая группа для заявок
- `ADMIN_USER_ID = 989604210`              — личный ID Кристины (ограничить админ-команды бота только ей)
- `CONSENT_VERSION = 2026-06-24`

## В ENV хостинга (секреты, не в репозиторий)
- `TELEGRAM_BOT_TOKEN = …`                 — из @BotFather
- `TELEGRAM_WEBHOOK_SECRET = …`            — сгенерировать: `openssl rand -hex 24`

## Ещё ждём от заказчика
- Хранение лидов — выбрать один вариант:
  - [ ] на старте только Telegram (быстро, без таблицы)
  - [ ] Google Sheets: `GOOGLE_SERVICE_ACCOUNT_JSON` (base64) + `SHEET_ID`
  - [ ] БД на РФ-хостинге (строгое 152-ФЗ) — `DATABASE_URL`
- `ALLOWED_ORIGIN = https://<домен лендинга>`   — поддомен или раздел сайта
- `YM_ID = …`                                   — счётчик Яндекс.Метрики (опц.)
- Юр. адрес оператора → вставить в `privacy.html`

## Заметка по chat_id
`-5481376613` — это **обычная** группа. Если позже Telegram превратит её в супергруппу (бывает при изменении настроек или росте), id сменится на формат `-100…`, и его нужно будет обновить в ENV. Чтобы не ловить это потом — можно сразу сделать группу супергруппой (включить историю для новых участников) и перепроверить id.
